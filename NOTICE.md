# Notice

This repository provides public workload templates and phase-level workload sequences reconstructed from the experimental trace used by the FiTune paper.

The templates invoke Vdbench, fio, IOR, MPI, Java, and other external tools. Those tools and their native libraries are separate dependencies and remain subject to their respective upstream licenses. Vdbench-native file trees are created by Vdbench's format-only preparation path rather than by a custom file-tree generator.
